# Clarity Workday - AI Workplace Productivity Assistant

## 📖 Project Overview
Clarity Workday is a modern, responsive web application designed to help professionals automate their daily workplace tasks using Artificial Intelligence. Built as part of the CAPACITI AI Skills Acceleration Programme, this application serves as a unified dashboard that brings multiple AI tools together into one seamless, SaaS-style platform. 

The goal of the project is to demonstrate practical AI implementation, effective prompt engineering, and responsible AI usage while providing a clean and intuitive user experience.

## ✨ Features Implemented
The application includes five integrated AI-powered tools within a single dashboard:
1. **Smart Email Generator:** Drafts professional emails in seconds, supporting multiple tones (Formal, Friendly, Persuasive).
2. **Meeting Notes Summarizer:** Transforms lengthy meeting notes into concise summaries, extracting key decisions, action items, and deadlines.
3. **AI Task Planner:** Helps users prioritize tasks and generate structured daily or weekly schedules.
4. **AI Research Assistant:** Provides structured briefs, insights, and summaries on any requested topic or article.
5. **AI Chatbot Interface:** An interactive, conversational AI assistant to help with general workplace queries.

### Key Design Requirements Met:
- Modern, professional SaaS-style dashboard UI.
- Intuitive sidebar navigation.
- Fully responsive design (Desktop and Mobile).
- Structured AI prompts with editable AI outputs.

## 🚀 Setup Instructions (Local Development)
Since this project was built using Lovable, the code is fully synced to this GitHub repository. To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   git clone https://github.com/mvuyolwethuuu-afk/Productivity-Assistant-AI.git

2. **Navigate into the project directory:**
   cd Productivity-Assistant-AI

3. **Install the dependencies:**
   npm install

4. **Start the local development server:**
   npm run dev

5. **View the app:** Open your browser and navigate to the local URL provided in your terminal (usually http://localhost:5173).

## 📂 Project Structure
Because modern applications are built modularly, the code is separated into different files rather than one single file to ensure maintainability and performance. The main structure looks like this:

- `public/` - Static assets (images, icons)
- `src/` - Main source code
  - `components/` - Reusable UI components (Sidebar, Buttons, Cards)
  - `pages/` - The individual feature pages (EmailGenerator, MeetingSummarizer, TaskPlanner, ResearchAssistant, AIChat)
  - `App.tsx` - Main application routing and layout
  - `index.css` - Global styles (Tailwind)
- `package.json` - Project dependencies and scripts
- `README.md` - Project documentation
- `vite.config.ts` - Vite configuration

## 📱 Usage
1. Open the [Live Application](https://clarityworkday.lovable.app).
2. Use the **Sidebar Navigation** on the left to select the AI tool you need.
3. Enter your prompt or paste your text into the input field.
4. The AI will generate a structured response. You can **edit the output** directly in the text box to fine-tune the results before copying or using them.
5. The dashboard is fully responsive; it can be used on both desktop and mobile browsers.

## 📦 Build for Production
If you want to build the app for a production environment, run the following command in your terminal:

npm run build

This will generate a `dist` folder with the optimized, minified files ready for deployment. You can preview the production build locally using `npm run preview`.
